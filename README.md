# CPCS 203 – Java Programming 2: Booking System

This repository contains the first assignment for ICS 203 (Programming 2) course.  
The project implements a **Flight Booking System** in Java, covering file handling, object-oriented programming, and basic ticket management.

## Project Overview

### Assignment 1 – BookingSystem
- **BookingSystem.java** – Main program that reads flight and passenger data from files, processes commands, and manages ticket bookings.  
- **Flight.java** – Represents a flight with flight number, departure/arrival cities, gate, seating map, and booking methods.  
- **Passenger.java** – Represents a passenger with passport number and name.  
- **Ticket.java** – Represents a booked ticket, calculates price including VAT, handles seat assignment and reservation confirmation.

### Features
- Add flights and passengers from input files.  
- Book tickets for passengers with seat selection and class type.  
- Generate invoices for individual tickets and flights.  
- Check seat availability before booking.  
- Calculate ticket prices based on class type, flight destination, and VAT.

## Topics Covered
- File I/O (reading and writing text files)  
- Object-Oriented Programming (Classes, Objects, Methods)  
- Arrays and data structures  
- Control statements and loops  
- Basic error handling and validation

## Language
